# Next of Kin Care - Website

Static website (HTML/CSS/JS). No build step or server needed.

## Structure
    next-of-kin-care/
      index.html          Page markup
      css/styles.css       All styling
      js/main.js           Menu, scroll reveal, form handling
      img/                 Your photos go here (see PLACE-IMAGES-HERE.txt)

## Preview
Open index.html in any browser (double-click it).

## Add your images
Drop the six photos into the img/ folder using the exact filenames listed in
img/PLACE-IMAGES-HERE.txt. They appear automatically - no code changes needed.

## Publish
Upload the whole next-of-kin-care folder to any host (Hostinger, Netlify,
GitHub Pages, cPanel, etc.). index.html must stay at the folder root with the
css, js and img folders beside it.
